===========================================
AXS TRADING APP - INSTALLATION GUIDE
===========================================

OPTION 1: Quick Launch (No Installation)
-----------------------------------------
1. Double-click "launch.vbs"
2. App opens silently (no terminal window)

OPTION 2: Create Desktop Shortcut
----------------------------------
1. Right-click "launch.vbs"
2. Select "Create shortcut"
3. Drag shortcut to Desktop
4. Right-click shortcut → Properties → Change Icon
5. Browse to: assets\icon.ico
6. Click OK

OPTION 3: Build Standalone .exe
--------------------------------
1. Open terminal in this folder
2. Run: npm install
3. Run: npm run build
4. Find "AXS-Trading.exe" in dist\ folder
5. Move it anywhere - it's completely portable!

The .exe file is a single portable executable.
No installation needed - just double-click to run.
